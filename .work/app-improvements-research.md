# App improvements research

- OWASP Logging Cheat Sheet: https://cheatsheetseries.owasp.org/cheatsheets/Logging_Cheat_Sheet.html
  - Log authentication successes/failures, authorization failures, session failures, configuration changes, user administration, imports/exports, and application errors.
  - Record when, where, who, and what; mask tokens, passwords, secrets, and sensitive PII.
- NIST backup guidance: https://csrc.nist.gov/pubs/other/2020/04/24/protecting-data-from-ransomware-and-other-data-los/final
  - Backups should be conducted, maintained, and tested; restore testing matters, not only backup creation.
- WHO storage/distribution guidance: https://iris.who.int/bitstreams/3bfa1a91-528f-4894-a2df-ce6b7fbe2e55/download
  - Health products should be rotated using first-expiry-first-out (FEFO).
